# Mirla Studio · web (mirlastudio.es)

Web de una página en HTML estático, sin compilación. Se publica con GitHub Pages desde la rama `main` (raíz). El archivo `CNAME` fija el dominio mirlastudio.es; no borrarlo.

## Archivos
- `index.html`: página principal. CSS y JS van dentro del propio archivo.
- `aviso-legal.html`: aviso legal y privacidad (LSSI y RGPD).
- `404.html`: página de error (GitHub Pages la usa sola).
- `favicon.svg`, `logo.png`, `apple-touch-icon.png`, `og.png`: iconos e imagen para compartir.
- `robots.txt`, `sitemap.xml`: SEO. Si añades una página, añádela al sitemap.
- `seo/`: copia de referencia de las etiquetas SEO.

## Identidad (A)
- Colores: crema `#F7F3EC`, tinta `#17150F`, ámbar `#E07B12` (texto ámbar sobre crema solo en `#A85608`; nunca `#E07B12` como texto sobre claro).
- Tipografías: Fraunces (titulares), Archivo (texto), JetBrains Mono (etiquetas).
- Símbolo: cabeza de mirlo con pico ámbar. Hero: bandada de mirlos en canvas que sigue al ratón.
- Animaciones: GSAP + ScrollTrigger (cdnjs) y Lenis (jsdelivr). Respetar `prefers-reduced-motion`.
- Cabecera, bandada y banda de servicios ocupan todo el ancho de la pantalla.
- Tono: tuteo, frases cortas, sin jerga, cercano.
