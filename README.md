# Mirla Studio · web

Web de https://mirlastudio.es (HTML estático, sin compilación).

- index.html: página principal
- aviso-legal.html: aviso legal y privacidad
- seo/: copia de referencia de las etiquetas SEO

Se publica con GitHub Pages desde la rama `main`: cada cambio que se sube a GitHub se publica solo en un par de minutos. El archivo `CNAME` fija el dominio; no borrarlo.

- 404.html: página de error
- Formulario de contacto: FormSubmit, envía a hola@mirlastudio.es
